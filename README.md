# Tangible Robotics — marketing site

Static landing page. Physical AI for the built world.

- `index.html` — the full single-page site (Atelier skin: warm paper + ink, terracotta accent, Instrument Serif).
- `img/` — photography assets.
- `demo/index.html` — Tangible Platform demo, served at `/demo/` (`/demo` redirects here).
- `demo-video/` — full-page video player at `/demo-video/`, with playback controls and muted autoplay.
- Deployed to https://tangible.derk.dev via Coolify (dockerfile buildpack, nginx).
